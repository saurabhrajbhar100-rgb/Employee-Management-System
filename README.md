# Employee Management System

A comprehensive Full-Stack Web Application designed for managing employee records efficiently with CRUD operations and user authentication.

## Features
- **User Authentication**: Secure Sign-up and Login functionality using JWT and bcryptjs.
- **Employee Directory**: View a complete list of employees with their details.
- **Add Employee**: Create new employee records including Name, Email, Position, and Salary.
- **Update Employee**: Edit existing employee information seamlessly.
- **Delete Employee**: Remove records from the database.
- **Responsive UI**: Modern and clean interface styled with CSS and FontAwesome icons.

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB, Mongoose
